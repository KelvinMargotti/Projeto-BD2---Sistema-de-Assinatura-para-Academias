# FutureFit - Sistema de Assinatura para Academias

Trabalho Final da disciplina de **Banco de Dados II**.

O **FutureFit** é o nosso projeto, que consiste na criação do modelo físico de um banco de dados para um **sistema de assinatura para academias**, que gerencia alunos, planos, assinaturas e pagamentos, com uma aplicação CRUD em **Python** conectada ao banco.

## Sobre o Sistema

O sistema permite que uma academia controle:

- Cadastro de alunos
- Planos disponíveis (mensal, trimestral, anual, etc.)
- Assinaturas dos alunos e seus status
- Pagamentos e mensalidades
